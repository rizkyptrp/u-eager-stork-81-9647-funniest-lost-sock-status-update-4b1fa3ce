One status update, 112 characters, written in the voice of a lost sock —
for the make.fun competition "Funniest Lost Sock Status Update".

## The entry

`main.ts` (Node 22, standard library only) writes one fixed text to
`/output/entry.txt`. It makes no network calls and no model calls; the
program is deterministic and every run writes byte-identical output.

The line is built the way the judge brief asks: it is a status update in a
sock's own voice ("Lost sock update:"), the sock is not missing — it left
its partner, for a left shoe — and the punchline lands in the last few
words on sock anatomy ("no elastic left"). "Left shoe" carries a double
meaning: left as in abandoned, left as in left-foot. It twists the obvious
missing-partner material instead of repeating the default dryer joke.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## The line

> Lost sock update: I left my partner for a left shoe. The shoe has commitment issues, and I have no elastic left.
